🔧 Firestore Security Rules Fix

Fix the "insufficient or missing permission" error

📋 Quick Instructions

1 Open Firebase Console

Go to Firebase Console

2 Navigate to Firestore Rules

Click: Firestore Database → Rules tab

3 Copy the Rules Below

4 Paste & Publish

Paste in Firebase Console and click Publish

📝 Security Rules (Click to Copy)

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { function isSignedIn() { return request.auth != null; } function isOwner(userId) { return isSignedIn() && request.auth.uid == userId; } function isAdmin() { return isSignedIn() && get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin'; } match /users/{userId} { allow read: if isOwner(userId); allow create: if isSignedIn() && request.auth.uid == userId; allow update: if isOwner(userId) && (!request.resource.data.diff(resource.data).affectedKeys().hasAny(['role', 'uid'])); allow read: if isAdmin(); allow update: if isAdmin(); } match /products/{productId} { allow read: if true; allow create, update, delete: if isAdmin(); } match /orders/{orderId} { allow read: if isSignedIn() && resource.data.userId == request.auth.uid; allow create: if isSignedIn() && request.resource.data.userId == request.auth.uid; allow read, update: if isAdmin(); } } }

✅ What These Rules Do

  • Users can read and update their own profile
  • Users CANNOT change their role to admin
  • Users CANNOT access other users' data
  • Anyone can view products
  • Only admins can manage products
  • Users can view and create their own orders
  • Admins have full access to everything
⚠️ Important: After publishing the rules, clear your browser cache (Ctrl+Shift+R) and try updating your profile again.
