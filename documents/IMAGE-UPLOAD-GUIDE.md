# 📸 Product Image Upload Guide

## Recommended Image Ratios & Sizes

### **Main Product Images**

**Optimal Ratio: 3:4 (Portrait) or 1:1 (Square)**

#### Desktop
- Container: 700px height
- Recommended: **1050px × 1400px** (3:4 ratio)
- Alternative: **1400px × 1400px** (1:1 square)
- Min Resolution: 800px × 1000px

#### Mobile
- Container: 300px - 400px height
- Same images work (responsive)
- Minimum: 600px × 800px

---

### **Product Thumbnails**

**Optimal Ratio: 1:1 (Square)**

- Container: 40px - 60px (circular)
- Recommended: **200px × 200px**
- Min Resolution: 100px × 100px
- Format: Square images work best in circles

---

### **Related Products**

**Optimal Ratio: 3:4 (Portrait)**

#### Desktop
- Container: 400px height
- Recommended: **600px × 800px**
- Alternative: **800px × 1000px**

#### Mobile
- Container: 180px - 240px height
- Same images work (responsive)
- Minimum: 360px × 480px

### **3. File Format & Quality**

**Format:**
- ✅ **JPEG** - Best for photos (smaller file size)
- ✅ **PNG** - Best for transparent backgrounds
- ✅ **WebP** - Modern format (best compression)
- ❌ **GIF** - Avoid (low quality)

**Quality:**
- Resolution: **72-150 DPI** (web standard)
- File Size: **100KB - 500KB** per image
- Compression: **80-90%** quality

**Color:**
- Color Space: **sRGB** (web standard)
- Bit Depth: **24-bit** (16.7 million colors)

## 🎯 Best Practices

### **Product Photography Tips**

1. **Aspect Ratio: 3:4 (Portrait)**
   - Width: 1050px
   - Height: 1400px
   - This fills the container perfectly

2. **Centering**
   - Keep product centered
   - Leave 10% padding around edges
   - Main focus in center 80%

3. **Background**
   - White or light gray recommended
   - Consistent across all products
   - No distracting elements

4. **Lighting**
   - Even, soft lighting
   - No harsh shadows
   - Consistent color temperature

## 📊 Image Ratio Calculator

### **For 3:4 Ratio (Recommended)**

If you have width, calculate height:
```
Height = Width × 1.33
```

Examples:
- 900px wide → 1200px height
- 1050px wide → 1400px height
- 1200px wide → 1600px height

### **For 1:1 Ratio (Square)**

```
Height = Width
```

Examples:
- 1000px wide → 1000px height
- 1400px wide → 1400px height
- 1600px wide → 1600px height

## 🔧 How to Resize Images

### **Using Online Tools:**

1. **Canva** (Free)
   - Create custom size: 1050 × 1400 px
   - Upload and crop
   - Download as JPEG

2. **Photopea** (Free Photoshop alternative)
   - Image → Image Size
   - Set to 1050 × 1400 px
   - Maintain aspect ratio
   - Export as JPEG

3. **TinyPNG** (Compression)
   - Upload image
   - Automatic compression
   - Download optimized

### **Bulk Resizing:**

For multiple images:
- **Bulk Resize Photos** (bulkresizephotos.com)
- **ILoveIMG** (iloveimg.com)
- Set target size: 1050 × 1400 px

## ⚠️ Common Mistakes to Avoid

❌ **Don't:**
- Use landscape (4:3) images
- Upload very wide images
- Use inconsistent ratios
- Upload low resolution (< 600px)
- Use large file sizes (> 1MB)
- Mix portrait and landscape

✅ **Do:**
- Use portrait (3:4) or square (1:1)
- Keep consistent ratio across products
- Optimize file size
- Use high quality images
- Center the product
- Use clean backgrounds
